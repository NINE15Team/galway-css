Start here

What this content controls

Three pieces of content drive the new PDP and collection grid. You create them once in Shopify Admin, then point collections (and sometimes products) at them.

1

Product Family

The Eyre / tech story block on the product page — badge, title, body, and three specs.

2

Feature Callouts

Chips near Add to Cart and the features grid further down the page. Same list, two places.

3

Collection Promo

The in-grid promo tile on a collection page (image + eyebrow + title + body + button).

↻

How it inherits

Set family + callouts on the exclusive pdp-* data collection. Products in that collection pick it up. Override on a product only when that SKU needs different chips.

Golden rule

pdp-* collections = shared defaults. Merch collections (Rainwear, Men’s, Best Sellers…) = shopping only — no family/callouts. Products = exceptions only.

Workflow

Do things in this order

Don’t assign metafields before the entries exist — Shopify needs something to pick.

  1. Content → Metaobjects

    Create Product Family entries

    One entry per fabric / tech family (Eyre Pro, Lightweight Rain, etc.).

  2. Content → Metaobjects

    Create PDP Feature entries

    Reusable feature chips (≈40 shared headlines). Create once, reuse everywhere.

  3. Products → Collections · pdp-*

    Assign family + features on each PDP data collection

    ✓ Done. Seven exclusive collections (pdp-eyre-pro … pdp-performance), 35 products, no overlaps. See Step 3.

  4. Products → (product)

    Override only when needed

    Leave product metafields empty unless that product needs different or extra features.

  5. Content → Metaobjects + Collections

    Add Collection Promo tiles

    Create promo creatives, then attach one to each collection that should show a tile.

2 Feature Callouts

Create the feature entries

Go to Content → Metaobjects → PDP Feature → Add entry. Each entry needs a Headline (and optional icon). Leave Body empty for chip-style features.

Shared family chips (use these on collections)

Create these first — they’re reused across many products.

3 Collections

PDP data collections (Option B — live)

Exclusive hidden-from-nav collections drive PDP inheritance. Not merch collections. Status: all 7 live · 35 products · 0 overlaps · Online Store only.

Live handles pdp-eyre-pro · pdp-lightweight-rain · pdp-eyre-flex · pdp-eyre-shield · pdp-hybrid · pdp-womens-rain · pdp-performance
Cleanup Merch collection Eyre Pro (eyre-pro) still has Product Family + Feature Callouts. Clear those metafields so only pdp-eyre-pro drives inheritance. Never set family/callouts on Rainwear, Men’s, Best Sellers, Hybrids, Women’s Rainwear, etc.

On each pdp-* collection:

Product Family Matching metaobject (e.g. eyre-pro)
Feature Callouts The 3 shared chips for that family (order matters)
Members Exactly the products listed — each SKU in one pdp-* only

4 Product overrides

Only when a SKU needs different chips

Most products inherit from their collection. Set product metafields only when you want 4–5 features (shared 3 + product-specific), or a different family story.

Example — Claddagh Chino Rain Pant

Collection already gives: 30K · 4-Way Stretch · Weather Protection

On the product, set Feature Callouts to something like:

30K Waterproof & Breathable 4-Way Stretch Weather Protection Rain Pant. Chino Look. Deep Golf Pockets

Product metafields fully replace the collection list — include the shared ones you still want.

Resolution order Product metafield → else first collection that has it → else hide that block.

Done?

Final checklist

  • All 8 Product Family entries exist (including none)
  • ~40 PDP Feature entries created (shared chips at minimum)
  • ✓ 7 pdp-* data collections have Product Family + Feature Callouts set
  • ✓ 35 products assigned with no overlaps
  • Clear family/callouts from merch Eyre Pro collection if still set
  • Accessories not on a pdp-* collection (or use family none)
  • Product overrides only where you need extra / different chips
  • Collection Promo entries created + assigned where a tile should show
  • Spot-check one PDP per family on the live preview
