## Metaobjects — create
### collection_promo (Collection Promo)
Storefront access ON. One entry per promo creative; assign to collections via metafield.

| Field | Key | Type |
| Eyebrow | eyebrow | Single line text |
| Title | title | Single line text |
| Body | body | Multi-line text |
| Button label | button_label | Single line text |
| Button link | button_link | URL |
| Image | image | File → Images |

Example entry (Full Kit):
- eyebrow: THE FULL KIT
- title: Shell, Pant, Midlayer
- body: Build the three-piece system that handles an Irish morning and a warm afternoon in the same round.
- button_label: Shop the System
- button_link: /collections/best-sellers
- image: (lifestyle shot)

## Metafields — Collections only
| Name | Namespace.key | Type |
| Collection Promo | custom.collection_promo | Metaobject → collection_promo |

## Resolution (theme)
### PDP (product_family / feature_callouts)
1. If product has the metafield set → use product
2. Else → use first product.collections[] that has it set
3. Else → hide dynamic block / keep theme-editor fallback

### Collection grid promo (collection_promo)
1. If collection.metafields.custom.collection_promo is set → show in-grid tile with that entry
2. Else → hide tile on storefront (theme-editor fallback still visible in design mode)
3. Position still controlled by section setting `promo_position` (0 = force hide)

## What each drives
| Metafield | UI |
| product_family | Eyre / tech module (badge, title, body, 3 specs) — image 2’s family story |
| feature_callouts | Chip strip near ATC (icon + headline) AND features grid (icon + headline + body) |
| collection_promo | In-grid collection promo tile (image, eyebrow, title, body, CTA) |

## Assign content — Option B (LIVE as of 2026-09-19)

Use **exclusive PDP data collections**, not merch collections.

| Handle | Family | Products |
| pdp-eyre-pro | eyre-pro | 4 |
| pdp-lightweight-rain | lightweight-rain | 4 |
| pdp-eyre-flex | eyre-flex | 9 |
| pdp-eyre-shield | eyre-shield | 6 |
| pdp-hybrid | hybrid | 8 |
| pdp-womens-rain | womens-rain | 2 |
| pdp-performance | performance-layers | 2 |

Rules:
1. Product Family + Feature Callouts live ONLY on these 7 `pdp-*` collections
2. Each product is in exactly one `pdp-*` collection (35 products, 0 overlaps)
3. Online Store channel only; do not add to navigation
4. Leave product metafields empty unless that SKU needs overrides (4–5 chips)
5. Never set family/callouts on merch collections (`rainwear`, `mens-1`, `best-sellers`, etc.)
6. **Cleanup:** clear Product Family + Feature Callouts from the merch collection **Eyre Pro** (`eyre-pro`) if still set — it competes with `pdp-eyre-pro` for theme inheritance
7. Collection Promo (`custom.collection_promo`) stays on real merch collections as needed
