How to update product & collection content

A plain-English guide for Galway. No coding needed — just Shopify Admin.

Think of it like this: you write the words in a content library, then point each product (or a group of products) at that content. The website fills in the rest.

The big picture

1. Content library — reusable text & images (called “metaobjects” in Shopify)

↓

2. Attach to a group of products — we use 7 special collections for this

↓

3. Product page shows it — story block, chips, badges, and more

For one product only (like a badge unique to Claddagh), you edit that product directly. For a whole fabric family (like all Eyre Pro pieces), you edit the shared collection.

What appears where on the product page

Each piece of custom content maps to a section shoppers see.

Near the title & price

1. Product badges

Small labels under or near the product name (e.g. waterproof callouts).

Where to edit: open the product → scroll to Metafields → Badges

Set on each product individually.

Under the product name

2. Short description

The one-line blurb (e.g. “Classic chino style. Rain-ready performance.”).

Where to edit: open the product → Metafields → Short description

Set on each product individually.

Near reviews / above Buy

3. Handpicked review

The featured quote and who said it (e.g. Gene V.).

Where to edit: open the product → Metafields →

  • Handpicked review quote — the words in quotes
  • Handpicked review author — the name
Near Add to cart · and again lower on the page

4. Feature callouts (chips & feature grid)

The icon + text pills (e.g. “30K Waterproof & Breathable”) and the longer “Why Choose…” feature cards further down.

Usually edited on a shared collection (see the 7 collections below), not on every product.

Content library: Content → Metaobjects → PDP Feature

Attach here: Collection → Metafields → Feature Callouts (pick several features, in order)

Only set Feature Callouts on a single product if that product needs different chips than its family.

The big fabric / tech story section

5. Product family (Eyre story)

The large block like “Powered by Eyre Pro™” — badge line, title, paragraph, three specs (Protection / Breathability / Mobility), and optional lifestyle image.

Usually edited on a shared collection so the whole family matches.

Content library: Content → Metaobjects → Product Family

Attach here: Collection → Metafields → Product Family (pick one family)

Collection listing pages (not the product page)

6. Collection promo tile

The promotional card mixed into a collection grid (image, eyebrow, title, button).

Content library: Content → Metaobjects → Collection Promo

Attach here: open a shopping collection (e.g. Best Sellers) → Metafields → Collection Promo

This is separate from the 7 PDP data collections. Full setup steps are in Part 2 — Collection pages.

How the 7 collections pass content to products

Instead of filling the same family story on 35 products, we put each product in one “data” collection and attach the family + features there once.

Example — Clifden Golf Rain Jacket

  1. Clifden sits in the collection PDP Data — Eyre Pro
  2. That collection has Product Family = Eyre Pro, and 3 Feature Callouts
  3. Clifden’s product page reads those automatically

Important rules

  • Each product should be in only one of these 7 collections
  • Don’t put Product Family / Feature Callouts on normal shopping collections (Men’s, Rainwear, Best Sellers…)
  • These 7 collections are for content only — they are not menu links for shoppers

Common tasks

A Change the Eyre Pro story for everyone in that family

  1. Go to Content → Metaobjects → Product Family
  2. Open Eyre Pro
  3. Edit the badge, title, body, or specs → Save

Every product in “PDP Data — Eyre Pro” updates together.

B Change the three chips for a whole family

  1. Open the matching PDP Data — … collection
  2. Find Metafields → Feature Callouts
  3. Add / remove / reorder features → Save

To change the wording of a chip itself: Content → Metaobjects → PDP Feature → open that feature.

C Update badges or short description for one product

  1. Open that product
  2. Metafields → Badges or Short description
  3. Save

D Add a new product to an existing family

  1. Open the matching PDP Data — … collection
  2. Add the product to that collection
  3. Fill that product’s own Badges / Short description / Handpicked review as needed

E One product needs different chips than its family

  1. Open that product
  2. Set Feature Callouts on the product
  3. Include every chip you want shown (product list replaces the collection list)

Part 2 — Collection pages

What appears where on a collection page

Every shopping collection (Men’s, Rainwear, Best Sellers…) uses the same page layout. Three optional blocks are driven by collection metafields. If a collection has nothing filled in, that block is simply hidden — the page never shows empty boxes.

Top banner

1. Hero (title, intro, background)

The big image banner with breadcrumb, collection name and intro text.

Where to edit: the collection’s built-in fields — no metafields needed.

  • Title → the heading
  • Description → the intro text under the heading
  • Collection image → the background photo (if empty, the default golfer image is used)
Strip under the hero

2. Callout bar (4 icons + text)

A row of up to four small icon + text items (e.g. “Free shipping over $100”).

Content library: Content → Metaobjects → the callout bar definition

Attach here: Collection → Metafields → Callout bar custom.callout_bar

Hidden when the collection has no callout bar attached.

Inside the product grid

3. Promo tile

A promotional card that sits in the grid in the 5th slot, first page only (image, eyebrow, title, text, button).

Content library: Content → Metaobjects → Collection Promo

Attach here: Collection → Metafields → Collection Promo custom.collection_promo

Hidden when nothing is attached. The slot number is a theme setting (Collection grid → Promo position).

Below the product grid

4. Feature section (heading + 3 cards)

A heading, intro paragraph and three icon cards explaining the collection’s technology.

Content library: Content → Metaobjects → the feature section definition

Attach here: Collection → Metafields → Feature section custom.feature_section

Hidden unless the attached entry has a heading.

Reviews, Rewards and FAQ below these are the same on every collection and are edited in the theme editor, not per collection.

One-time setup (developer / admin)

Only needed if the definitions don’t exist yet (e.g. on a new store). Keys must match exactly — the theme looks them up by key, not by name.

1 Create the metaobject definitions

Settings → Custom data → Metaobjects → Add definition. Create three, with these field keys:

Settings → Custom data → Collections → Add definition:

Filling in a collection

F Give a collection its callout bar, promo and feature section

  1. Go to Content → Metaobjects, pick the definition (e.g. Collection Promo) → Add entry
  2. Name the entry clearly (e.g. “Rainwear promo — autumn”), fill the fields → Save
  3. Open Products → Collections → the collection (e.g. Rainwear)
  4. Scroll to Metafields → click Callout bar / Collection Promo / Feature section → choose the entry → Save
  5. View the collection on the site and refresh

G Reuse the same content on several collections

Attach the same entry to each collection. Editing the entry later updates every collection that uses it — handy for a store-wide callout bar.

H Remove a block from one collection

  1. Open the collection → Metafields
  2. Clear the field (e.g. Collection Promo) → Save

Don’t delete the metaobject entry itself if other collections still use it.

I Swap the promo for a sale

  1. Create a new Collection Promo entry for the sale
  2. On each collection, point Collection Promo at the new entry
  3. After the sale, point it back to the old entry (keep it — don’t delete)

Quick reference

I want to change… I edit…
Badges on one product That product → Badges
Short description That product → Short description
Featured review quote That product → Handpicked review fields
Family story (Eyre Pro, etc.) Metaobjects → Product Family
Which chips a family shows PDP Data collection → Feature Callouts
Chip wording / icon Metaobjects → PDP Feature
Collection heading, intro, banner image Collection → Title / Description / Collection image
Icon strip under the collection banner Shopping collection → Callout bar
Promo tile in the collection grid Shopping collection → Collection Promo
Heading + 3 cards under the grid Shopping collection → Feature section

Tip: After saving, open the live product page and refresh. If something is missing, check the product is in the right PDP Data collection and that collection has its metafields filled in. On a collection page, check the metafield is attached to that collection and the metaobject definition has Storefronts access on.
