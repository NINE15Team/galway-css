Update product page story + feature chips via 7 data collections.

How it works (simple)

  1. Metaobjects = the content library
    Content → Metaobjects → Product Family or PDP Feature. Edit the copy there.
  2. Metafields on a collection = “use this content for these products”
    Products → Collections → open a pdp-* collection → Metafields → Product Family / Feature Callouts.
  3. Products in that collection pick it up automatically.
    Leave product metafields empty unless one SKU needs different chips.
Where to change wording
Change family story → edit the Product Family entry.
Change chip text → edit the PDP Feature entry.
Change which products get which story → move products between the 7 collections below (or change that collection’s metafields).

Day-to-day tasks

New product in an existing family

Add it to the matching pdp-* collection only. Don’t put family metafields on Rainwear / Men’s / Best Sellers.

Update shared chips for a whole family

Open that pdp-* collection → Feature Callouts → pick different features (or edit the feature entries themselves).

One product needs different chips

On that product, set Feature Callouts. Product overrides replace the collection list — include any shared chips you still want.

Hide the Eyre block (accessories)

Don’t add to a pdp-* collection. Or set Product Family to none / leave blank.

Don’t set Product Family or Feature Callouts on normal shopping collections (Rainwear, Men’s, Best Sellers, etc.). Only the 7 pdp-* collections above.

If merch collection Eyre Pro still has those metafields, clear them — they can conflict with pdp-eyre-pro.

Quick check

Open a product in one of the 7 collections with empty product metafields. You should see that family’s chips + story. If not: confirm membership + collection metafields are filled.
