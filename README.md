# Galway CSS + content guides

## GitHub Pages

Serve the content guides from the `/docs` folder:

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` · Folder: `/docs`
4. Save

Site URL will look like:
`https://nine15team.github.io/galway-css/`

| Path | What |
|---|---|
| `/` or `/index.html` | Main content setup guide |
| `/CONTENT_GUIDE.html` | Same guide (alias) |
| `/collection_metafields.plan.html` | Live PDP data collections map |
| `/product_family.entries.html` | Family metaobject copy sheet |
| `/pdp_feature.TOP40.html` | Shared + product feature chips |
| `/pdp_feature.entries.html` | Full feature dump |
| `/product_assignments.html` | Per-product override reference |
| `/SCHEMA.txt` | Metafield / metaobject schema |

`base.css` at repo root is the theme CSS reference (not part of the Pages docs site unless you link it).
